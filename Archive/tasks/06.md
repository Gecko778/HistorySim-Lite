# HistorySim Lite 课程任务卡

## 第 6 次课：内政开发、资源增长与数值边界

### 一、本次主题

本次课完善 DEVELOP 命令和经济结算规则，建立农业、商业、治安、城防、人口、粮草等状态更新机制。

### 二、课程目标

1. 设计透明、可测试的资源公式。
2. 将政治属性、治安和技能修正纳入内政。
3. 处理数值上限、下限和异常状态。
4. 将经济结算接入回合管线。

### 三、任务：课堂完成

3. 将农业、商业、治安、城防限制在 0-100。
4. 写 2 个开发测试。

### 四、任务：课后延拓

1. 实现每回合粮草、金钱、人口变化。
2. 让治安影响产出。
3. 写边界测试。
4. 完成 docs/ECONOMY_RULES.md。

### 五、知识点

数值公式应简单、透明、可解释。开发收益可采用：基础值 × 太守政治修正 × 治安修正 × 技能修正。所有核心状态都要限制在合理范围内，防止长期模拟后出现负数或荒谬值。

### 六、示例框架代码（TS 版）

```ts
export function clamp(v: number, min: number, max: number): number { return Math.max(min, Math.min(max, v)); }

export function calculateDevelopmentGain(region: Region, governor?: Person, skillModifier = 1): number {
  const base = 2;
  const politics = governor?.politics ?? 50;
  const politicsModifier = 1 + politics / 200;
  const orderModifier = clamp(region.publicOrder, 20, 100) / 100;
  return Math.max(1, Math.round(base * politicsModifier * orderModifier * skillModifier));
}

export function developRegion(region: Region, target: "agriculture" | "commerce" | "publicOrder" | "defence", governor?: Person): Region {
  const gain = calculateDevelopmentGain(region, governor, 1);
  return { ...region, [target]: clamp(region[target] + gain, 0, 100) };
}

export function settleRegionEconomy(region: Region): Region {
  const foodGain = Math.round(region.agriculture * 12 * (region.publicOrder / 100));
  const populationDelta = region.publicOrder >= 50 ? Math.round(region.population * 0.002) : -Math.round(region.population * 0.003);
  return { ...region, food: Math.max(0, region.food + foodGain), population: Math.max(0, region.population + populationDelta) };
}
```

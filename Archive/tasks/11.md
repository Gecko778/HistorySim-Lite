# HistorySim Lite 课程任务卡

## 第 11 次课：AI 决策、效用评分与候选行动

### 一、本次主题

本次课为 AI 势力建立候选行动生成、效用评分和行动选择机制。AI 目标是合理、可解释、可测试。

### 二、课程目标

1. 说明启发式 AI 的作用。
2. 生成 AI 候选行动集合。
3. 设计发展、征兵、攻击评分。
4. 输出 AI 决策理由。

### 三、任务：课堂完成

1. 实现 evaluateRegionDevelopmentNeed()。
2. AI 选择最需要开发的地区。
3. 生成 DEVELOP 命令。
4. 写评分测试。

### 四、任务：课后延拓

1. 生成发展、征兵、攻击 3 类候选行动。
2. 每个 AI 势力每回合选择 1-3 个行动。
3. 输出候选评分表。
4. 完成 docs/AI_DESIGN.md。

### 五、知识点

AI 不应完全随机。基本过程是：生成候选行动，计算每个行动的效用分数，选择分数最高的若干行动。评分函数应能解释，例如目标地区价值、敌方弱度、边境压力、粮草风险。

### 六、示例框架代码（TS 版）

```ts
export interface AiCandidate { command: Command; score: number; reason: string; }

export function evaluateRegionDevelopmentNeed(region: Region): number {
  return (100 - region.agriculture) * 0.35 + (100 - region.commerce) * 0.25 + (100 - region.publicOrder) * 0.4;
}

export function generateDevelopCandidates(state: GameState, faction: Faction): AiCandidate[] {
  return Object.values(state.regions).filter(r => r.ownerFactionId === faction.id).map(region => ({
    score: evaluateRegionDevelopmentNeed(region),
    reason: `${region.name} needs development.`,
    command: { type: "DEVELOP", source: "ai", factionId: faction.id, regionId: region.id, target: region.publicOrder < 60 ? "publicOrder" : "agriculture" },
  }));
}

export function planAiCommands(state: GameState, faction: Faction): Command[] {
  return generateDevelopCandidates(state, faction).sort((a,b) => b.score - a.score).slice(0, 2).map(c => c.command);
}
```

# HistorySim Lite 课程任务卡

## 第 16 次课：综合交付、答辩展示与验收闭环

### 一、本次主题

本次课完成最终集成、演示、答辩和项目反思。展示重点是算法、架构、测试和工程闭环。

### 二、课程目标

1. 演示完整系统运行流程。
2. 说明核心算法与复杂度。
3. 说明分层架构与模块职责。
4. 展示测试报告和 20 回合模拟结果。
5. 完成个人贡献说明。

1. 启动 Tauri 应用。
2. 加载标准剧本。
3. 演示地图、命令、AI、事件、战斗、存档。
4. 展示测试结果。

### 四、任务：课后延拓

1. 整理最终仓库。
2. 补全文档。
3. 提交答辩材料。
4. 提交 CONTRIBUTION.md。
5. 打最终 tag。

### 五、知识点

答辩不应只展示界面，应形成“需求 -> 设计 -> 实现 -> 测试 -> 演示 -> 反思”的闭环。学生应说明技术债和限制，例如 AI 简化、战斗公式未平衡、事件配置表达力有限、地图不是真实地理图。

### 六、示例框架代码（TS 版）

```ts
export interface FinalCheckResult { passed: boolean; messages: string[]; }

export function checkFinalAcceptance(state: GameState): FinalCheckResult {
  const messages: string[] = [];
  if (Object.keys(state.regions).length !== 30) messages.push("Region count is not 30.");
  if (Object.keys(state.factions).length !== 4) messages.push("Faction count is not 4.");
  if (Object.keys(state.persons).length !== 50) messages.push("Person count is not 50.");
  if (state.turn < 1) messages.push("Invalid turn number.");
  return { passed: messages.length === 0, messages };
}
```

### 八、验收标准

- 术语、数量和基础命令与统一项目范围一致。
- TypeScript Core 中的代码不依赖 React、PixiJS 或 Tauri UI。
- 课堂任务能够在本地运行或通过测试验证。

# HistorySim Lite 课程任务卡

## 第 13 次课：React 与 PixiJS 地图 UI、交互面板

### 一、本次主题

本次课完善地图可视化和交互界面，实现 Map View、Region and Faction Panel、Person and Appointment Panel 的联动。

### 二、课程目标

1. 使用 React 管理选择状态。
2. 使用 PixiJS 渲染地区、连接线、势力颜色和军队图标。
3. 将地图点击事件转化为 React 状态。
4. 展示地区、势力和人物详情。

### 三、任务：课堂完成

1. 点击地图地区节点。
2. Region Panel 显示地区数据。
3. 高亮选中地区。
4. 显示所属势力颜色。

### 四、任务：课后延拓

1. 显示选中地区人物列表。
2. 按政治或统率排序。
3. 在 UI 中生成 APPOINT 命令。
4. 完成 docs/UI_DESIGN.md。

### 五、知识点

React 负责状态、表单、面板和命令提交，PixiJS 负责地图绘制。建议引入 ViewModel，将 GameState 转换为地图节点、边、图标等显示数据，避免 UI 中混入复杂领域逻辑。

### 六、示例框架代码（TS 版）

```ts
interface GameScreenProps { state: GameState; onCommand: (command: Command) => void; }

export function GameScreen({ state, onCommand }: GameScreenProps) {
  const [selectedRegionId, setSelectedRegionId] = useState<string | undefined>();
  const selectedRegion = selectedRegionId ? state.regions[selectedRegionId] : undefined;
  return (
    <div className="game-screen">
      <MapCanvas regions={Object.values(state.regions)} factions={state.factions} selectedRegionId={selectedRegionId} onSelectRegion={setSelectedRegionId} />
      <RegionPanel region={selectedRegion} faction={selectedRegion ? state.factions[selectedRegion.ownerFactionId] : undefined} />
      {selectedRegion && <button onClick={() => onCommand({ type: "DEVELOP", source: "player", factionId: selectedRegion.ownerFactionId, regionId: selectedRegion.id, target: "agriculture" })}>Develop</button>}
    </div>
  );
}
```

# HistorySim Lite 课程任务卡

## 第 3 次课：地图图模型与 PixiJS 节点地图基础渲染

### 一、本次主题

本次课将 30 个地区抽象为 Region Graph，并使用 PixiJS 在 React 中渲染节点、连接线和势力颜色。

### 二、课程目标

1. 使用邻接表表示地图关系。
2. 检查地图连通性和双向边一致性。
3. 理解 Region 坐标与渲染坐标的关系。
4. 使用 PixiJS 渲染节点地图。

### 三、任务：课堂完成

1. 实现 buildRegionGraph()。
2. 实现 validateUndirectedEdges()。
3. 用 PixiJS 渲染 5 个地区节点和连接线。
4. 点击节点后显示地区名称。

### 四、任务：课后延拓

1. 扩展至 30 个地区和至少 40 条连接。
2. 使用 4 种势力颜色。
3. 完成 docs/MAP_GRAPH.md。
4. 地图中显示选中地区高亮。

### 五、知识点

地图在 Core 中是图，在 Rendering 中是图形。算法读取 Region.neighbours，PixiJS 只读取 x、y、ownerFactionId 等渲染状态。该分离能保证路径搜索、AI 和测试不依赖画面。

### 六、示例框架代码（TS 版）

```ts
export type RegionGraph = Record<string, string[]>;

export function buildRegionGraph(regions: Record<string, Region>): RegionGraph {
  return Object.fromEntries(Object.values(regions).map(r => [r.id, [...r.neighbours]]));
}

export function validateUndirectedEdges(regions: Record<string, Region>): string[] {
  const issues: string[] = [];
  for (const region of Object.values(regions)) {
    for (const nextId of region.neighbours) {
      const next = regions[nextId];
      if (!next) issues.push(`${region.id} references missing ${nextId}`);
      else if (!next.neighbours.includes(region.id)) issues.push(`${region.id} -> ${nextId} is not symmetric`);
    }
  }
  return issues;
}

// PixiJS/React 伪骨架
export interface RegionNodeVM { id: string; name: string; x: number; y: number; colour: string; selected: boolean; }
export function toRegionNodes(regions: Region[], factions: Record<string, Faction>, selected?: string): RegionNodeVM[] {
  return regions.map(r => ({ id: r.id, name: r.name, x: r.x, y: r.y, colour: factions[r.ownerFactionId]?.colour ?? "#999999", selected: r.id === selected }));
}
```

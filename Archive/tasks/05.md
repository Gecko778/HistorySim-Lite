# HistorySim Lite 课程任务卡

## 第 5 次课：GameState、Command 与回合推进

### 一、本次主题

本次课建立以 GameState 为中心的回合推进机制，设计玩家与 AI 共用的 Command 模型。

### 二、课程目标

1. 说明 GameState 的中心地位。
2. 设计 5 类基础 Command 的联合类型。
3. 区分命令校验、命令执行和日志生成。
4. 实现 advanceTurn() 最小管线。

### 三、任务：课堂完成

1. 定义 Command 类型。
2. 实现 DEVELOP 命令的最小执行。
3. 生成 TurnLog。
4. 让 advanceTurn() 独立运行。

### 四、任务：课后延拓

1. 完善 10 步回合流程。
2. 加入命令校验和错误日志。
3. 编写 3 个命令校验测试。
4. 完成 docs/TURN_PIPELINE.md。

### 五、知识点

Command Pattern 将用户或 AI 的行动意图封装为对象。UI 只提交 Command，Core 负责校验和执行。回合管线为后续经济、战斗、事件、AI 和存档提供统一入口。

### 六、示例框架代码（TS 版）

```ts
export type Command =
 | { type: "DEVELOP"; source: "player" | "ai"; factionId: string; regionId: string; target: "agriculture" | "commerce" | "publicOrder" | "defence" }
 | { type: "RECRUIT"; source: "player" | "ai"; factionId: string; regionId: string; amount: number }
 | { type: "MOVE_ARMY"; source: "player" | "ai"; factionId: string; armyId: string; fromRegionId: string; toRegionId: string }
 | { type: "ATTACK"; source: "player" | "ai"; factionId: string; armyId: string; targetRegionId: string }
 | { type: "APPOINT"; source: "player" | "ai"; factionId: string; personId: string; role: "governor" | "general"; targetId: string };

export function advanceTurn(state: GameState, commands: Command[]): GameState {
  let next = structuredClone(state);
  for (const command of commands) next = executeCommand(next, command);
  next.turn += 1;
  next.date = advanceMonth(next.date);
  return next;
}

function executeCommand(state: GameState, command: Command): GameState {
  const next = structuredClone(state);
  if (command.type === "DEVELOP") {
    const r = next.regions[command.regionId];
    r[command.target] = Math.min(100, r[command.target] + 2);
    next.logs.push({ turn: next.turn, category: "command", message: `${r.name} ${command.target} +2` });
  }
  return next;
}
```

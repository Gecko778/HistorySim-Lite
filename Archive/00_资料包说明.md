# HistorySim Lite：历史策略模拟系统教学案例资料包说明

版本：v1.0  
日期：2026-05-09

## 一、资料包定位

本资料包用于《算法与软件架构》课程的项目制教学实施。资料包围绕一个完整的单一案例展开，即 **HistorySim Lite（历史策略模拟系统）**。该案例以历史模拟类应用为背景，通过地图建模、角色数据、势力关系、技能配置、回合推进、战斗结算、AI 决策和可视化界面，引导学生在完整项目中学习算法设计与软件架构设计。

课程实施时，学生应根据任务指导书完成代码实现、测试、文档和答辩展示。

## 二、统一项目范围

为保持课程实施、作业验收和评分的一致性，本案例采用以下统一规模：

| 项目元素 | 标准规模 |
|---|---:|
| 地区（Region） | 30 个 |
| 势力（Faction） | 4 个 |
| 历史人物（Person） | 50 个 |
| 技能（Skill） | 20 个 |
| 事件（Event） | 10 个 |
| 基础命令（Command） | 5 类 |
| 核心算法组 | 5 组 |
| 主要界面/面板 | 4 组 |
| 教学实施单元 | 16 次，每次 90 分钟 |

基础命令固定为：开发（DEVELOP）、征兵（RECRUIT）、移动（MOVE_ARMY）、攻击（ATTACK）、任命（APPOINT）。

核心算法组固定为：地图图模型与路径搜索、排序与优先级评估、资源增长与状态更新、战斗结算、AI 效用评分与行动选择。

## 四、使用建议

教师可先将本资料包作为课程实施主文档使用，再根据本校课时、学生基础和技术栈进行局部裁剪。正式发布给学生时，建议至少发布以下文件：

1. 02_案例需求与范围说明.md；
2. 05_分阶段任务指导书.md；

4. 07_验收标准与评分量规.md；

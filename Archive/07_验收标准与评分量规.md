# 验收标准与评分量规

## 一、验收原则

HistorySim Lite 的验收基本原则是：功能闭环、算法可解释、架构可维护、测试可复现、文档完整。项目不以界面美观作为主要评价依据，但界面应足以支持地图查看、命令输入和日志查看。

## 二、最终验收清单

| 编号 | 验收项 | 标准 |
|---|---|---|
| A01 | 数据规模 | 包含 30 个 Region、4 个 Faction、50 个 Person、20 个 Skill、10 个 Event |
| A02 | 地图连通 | 30 个地区形成连通图，至少 40 条连接关系 |
| A03 | 地图显示 | 可通过颜色区分 4 个势力控制区 |
| A04 | 信息查看 | 可查看地区、势力、人物详情 |
| A05 | 基础命令 | 支持 DEVELOP、RECRUIT、MOVE_ARMY、ATTACK、APPOINT |
| A06 | 回合推进 | 系统能连续推进至少 20 个回合 |
| A07 | AI 行动 | AI 势力每回合能生成 1 至 3 个行动 |
| A08 | 战斗结算 | 攻击可产生胜负、伤亡和日志 |
| A09 | 事件系统 | 事件能根据条件触发并改变状态 |
| A10 | 存档读档 | 可保存和读取 GameState |
| A11 | 测试 | 核心算法具有测试用例 |
| A12 | 文档 | 需求、架构、算法、测试、用户说明完整 |
| A13 | 复现 | 固定随机种子时可复现关键结果 |
| A14 | 答辩 | 能解释算法、架构和测试结果 |

## 三、评分结构

| 类别 | 权重 |
|---|---:|
| 过程性评价 | 50% |
| 终结性评价 | 50% |

## 四、过程性评价

| 项目 | 权重 | 评价重点 |
|---|---:|---|
| 阶段任务完成 | 20% | 是否按任务要求持续提交阶段成果 |
| Git 与协作记录 | 10% | 提交频率、提交说明、分支管理、合并记录 |
| 阶段测试与问题修复 | 10% | 是否及时发现并修复错误 |
| 课堂参与与小组协作 | 10% | 是否参与讨论、评审、演示和互评 |

## 五、终结性评价

| 项目 | 权重 | 评价重点 |
|---|---:|---|
| 系统完整度 | 15% | 是否形成可运行闭环 |
| 算法应用深度 | 10% | 路径搜索、战斗、AI、资源增长是否合理 |
| 架构设计质量 | 10% | 模块边界、依赖关系、可测试性和可扩展性 |
| 测试质量 | 5% | 单元测试、集成测试、边界测试和复现测试 |
| 文档质量 | 5% | 文档完整、术语统一、图表清晰 |
| 答辩展示 | 3% | 演示清晰，能回答关键问题 |
| 个人贡献说明 | 2% | 贡献真实、具体、可核查 |

## 六、算法评分标准

| 等级 | 标准 |
|---|---|
| 优秀 | 算法选择合理，公式清晰，有复杂度分析，有充分测试，能解释设计权衡 |
| 良好 | 主要算法正确，测试基本充分，能说明基本复杂度 |
| 合格 | 算法能支撑系统运行，但说明较简单，测试覆盖有限 |
| 不合格 | 核心算法缺失、不可解释或明显错误 |

## 七、架构评分标准

| 等级 | 标准 |
|---|---|
| 优秀 | 分层清晰，模块职责明确，模拟内核可独立测试，规则和事件具备扩展性 |
| 良好 | 模块划分基本合理，主要依赖关系清楚，核心模块可测试 |
| 合格 | 系统能够运行，但部分功能耦合明显，文档说明较弱 |
| 不合格 | UI、数据、算法和状态逻辑混杂，难以维护和测试 |

## 八、数据评分标准

| 等级 | 标准 |
|---|---|
| 优秀 | 数据完整，引用一致，数值平衡，能支持多回合模拟 |
| 良好 | 数据基本完整，少量数值需要调整 |
| 合格 | 数据达到数量要求，但平衡性和一致性一般 |
| 不合格 | 数据缺失、引用错误或无法支持系统运行 |

## 九、测试评分标准

| 等级 | 标准 |
|---|---|
| 优秀 | 覆盖路径、命令、战斗、AI、事件、存档和复现测试 |
| 良好 | 覆盖主要算法和关键流程 |
| 合格 | 仅覆盖部分核心函数 |
| 不合格 | 无有效测试，或测试无法运行 |

## 十、扣分项

出现以下情况应酌情扣分：

1. 数据规模未达到标准；
2. 不能连续推进 20 回合；
3. AI 行动完全随机且无评分逻辑；
4. 战斗结果无法解释；
5. 随机结果无法复现；
6. 关键功能依赖手工修改数据；
7. 文档与系统实现明显不一致；
8. 小组成员贡献严重失衡且无说明；
9. 抄袭、伪造提交记录或伪造测试结果。
